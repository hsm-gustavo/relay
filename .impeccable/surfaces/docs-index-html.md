# Relay website

Mode: Persuade. Help a developer evaluate and download Relay. Keep the existing user guide and deep links in the same static page.

## Direction contract

**Thesis.** Show a real request and response in context, at a size a developer can inspect.

**Visual system.** A software catalog printed in lavender, paper white, and blue-black, with citron for the download. Use wide sans-serif type and thin index rules. Keep the app screenshot's original colors.

**Story.** Identify Relay as a desktop HTTP client, see what happens in the workspace, then choose a build or follow the first request.

**First viewport.** Set the proposition across the page, with a compact action column beside the heading. Below, let the wide screenshot dominate a framed lavender surface. Native disclosure controls lead through request tabs, response inspection, and collections, with a matching highlight on the app capture.

**Form.** Software catalog with annotated workspace, grounded candidate six, seed 95cbdac2. The user chose direct implementation.

**Finish.** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
