## Platform

web

## Users

The website primarily serves developers evaluating Relay for the first time. Returning users need a direct route to installation instructions and the complete user guide.

## Product Purpose

Relay is a local desktop HTTP client for sending API requests, inspecting responses, saving collections, and reusing environment values. The site helps visitors see the actual workspace, choose a download, and send a first request.

## Capabilities and Constraints

The website ships as static HTML, CSS, and optional browser JavaScript from `docs/`. Published release packages target 64-bit Linux and Windows. The guide also covers building from source. Keep the existing section links available to readers.

## Evidence on Hand

The Relay icon and a real desktop workspace capture are in `docs/assets/`. The existing user guide and repository document the app's behavior.
